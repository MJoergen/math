# latex
Mathematical notes written in LaTeX. Some are in English, and some are in
Danish.

Run `make` to build the PDFs of the files below.

* [`cassette.tex`](cassette.tex): The relationship between the counter reading
  and the elapsed playing time on a cassette tape, and how to fit this model
  to measurements.
* [`elliptic.tex`](elliptic.tex): Elliptic functions, starting from
  Weierstrass' P-function. In Danish.
* [`euler.tex`](euler.tex): A solution to Project Euler problem 318, which is
  about the number of nines after the decimal point in the powers of
  $\sqrt 2 + \sqrt 3$.
* [`fjerde.tex`](fjerde.tex): Solving the general quartic equation using
  permutations of the roots. In Danish.
* [`modular.tex`](modular.tex): Modular forms: The Jacobi theta function and
  the $j$-invariant.
* [`pell.tex`](pell.tex): A recurrence relation whose solutions are given by
  Pell's equation.
* [`pendulum.tex`](pendulum.tex): Two ways of solving the pendulum equation.
* [`quintic.tex`](quintic.tex): Links to references about solving quintic
  equations.
* [`tredje.tex`](tredje.tex): Exercises in solving cubic equations, both
  algebraically and using trigonometric functions. In Danish.

The folders [`MA`](MA) and [`Systime`](Systime) contain more LaTeX documents.
