# latex
Mathematical notes written in LaTeX. Some are in English, and some are in
Danish.

Run `make` to build the PDFs of the documents below. Each PDF is placed next
to its `.tex` file.

* [`cassette`](cassette): The relationship between the counter reading
  and the elapsed playing time on a cassette tape, and how to fit this model
  to measurements.
* [`elliptic`](elliptic): Elliptic functions, starting from
  Weierstrass' P-function. In Danish.
* [`euler`](euler): A solution to Project Euler problem 318, which is
  about the number of nines after the decimal point in the powers of
  $\sqrt 2 + \sqrt 3$.
* [`fjerde`](fjerde): Solving the general quartic equation using
  permutations of the roots. In Danish.
* [`modular`](modular): Modular forms: The Jacobi theta function and
  the $j$-invariant.
* [`pell`](pell): A recurrence relation whose solutions are given by
  Pell's equation.
* [`pendulum`](pendulum): How the pendulum equation is related to the
  equation $\ddot x = x - \frac12 x^3$, shown in both directions.
* [`quintic`](quintic): Links to references about solving quintic
  equations.
* [`tredje`](tredje): Exercises in solving cubic equations, both
  algebraically and using trigonometric functions. In Danish.

The folders [`MA`](MA) and [`Systime`](Systime) contain more LaTeX documents.
