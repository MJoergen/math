# elliptic
Elliptiske funktioner (August 2015). In Danish.

The document `elliptic.tex` introduces elliptic functions, starting from
Weierstrass' $\wp$-function for a lattice $L$ spanned by two complex periods
$\omega_1$ and $\omega_2$. It covers:

* Basic properties: the function is analytic, even and doubly periodic.
* The Taylor expansion.
* The differential equation satisfied by the function.
* The addition formula.
* The values at half periods.
* The inverse function.
