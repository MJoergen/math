# tredje
Løsning af trediegradsligninger (March 2017). In Danish.

The document `tredje.tex` contains three exercises in solving cubic equations:

1. Solving $x^3 + px + q = 0$ algebraically by writing $x = u + v$.
2. Finding all three solutions using trigonometric functions.
3. Reducing the general cubic $x^3 + ax^2 + bx + c = 0$ to the form above,
   using the substitution $x = u - a/3$.
