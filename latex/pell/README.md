# pell
Pell's Equation (August 2022).

The document `pell.tex` studies the recurrence relation

$$x_{n+1} = 2x_n^2 - 1, \qquad y_{n+1} = 2x_n y_n$$

and shows that $x_n/y_n$ converges to $\sqrt{x_0^2-1}/y_0$. The key is
that $(x_n^2 - 1)/y_n^2$ does not change from one step to the next.

It then connects this to solutions of Pell's equation $x^2 - dy^2 = 1$, and
lists several properties of these solutions.
