# fjerde
Løsning af fjerdegradsligninger (March 2017). In Danish.

The document `fjerde.tex` solves the general quartic equation
$x^4 + ax^3 + bx^2 + cx + d = 0$ by using group theory and symmetric
polynomials, i.e. by studying how expressions in the roots change when the
roots are permuted. It reduces the problem to a cubic equation, solves that,
and then finds the four roots.

It also calculates the discriminant, and finishes with a worked example.
