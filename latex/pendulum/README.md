# pendulum
The Pendulum Equation (May 2022).

The document `pendulum.tex` shows how the pendulum equation
$\ddot y + \sin y = 0$ is related to the equation
$\ddot z + \frac12 z^3 - Kz = 0$, where $z = \dot y$.

* One way: Starting from the pendulum equation, derive the equation for
  $z = \dot y$.
* The other way: Starting from $\ddot x = x - \frac12 x^3$ with $x = \dot y$,
  show that $y$ satisfies a pendulum equation $\ddot y = A\sin(y - y_0)$.
